INTRODUCTIONCoin and cashless payment, in one box

The Sintron ST-004/ST-005 is an upgraded version of our renowned model, the ST-002/ST-003. Equipped with an LCD and Mobile Payment functionality, it serves as a power timer control for seamless operation. This timer box allows you to effortlessly connect your machine, enabling users to make payments through Apple Pay, Google Pay, Paypal, Venmo, Debit & Credit Cards…(not limited), or Coins. Enjoy the flexibility of setting up time, price, and text displayed on LCD Screen. It is particularly well-suited for 110V~240V Washer & dryers, as well as any machines requiring a timer.

PART 1Coin acceptor and timer settings

ALREADY CONFIGURED?
  • US customers using quarters only — the coin acceptor is pre-configured. Go straight to Step 1.3.
  • Canadian customers using $0.25, $1 and $2 coins — also pre-configured. Go straight to Step 1.3.
⚠ CANADIAN COINS — READ IF USING $1 OR $2

$1 and $2 coins minted before and after 2011 have different physical characteristics, so they are pre-configured as separate coin channels:

  • L1 — $0.25 coins
  • L2 — $1 coins minted in 2011 or earlier
  • L3 — $1 coins minted after 2011
  • L4 — $2 coins minted in 2011 or earlier
  • L5 — $2 coins minted after 2011

To stop the machine taking one of these coins, set that channel’s value to 0 — see Step 1.2.

💡 Using tokens instead of coins? See token details.

Sintron ST-001 coin setup

The box is equipped with a coin acceptor model: Sintron ST-001, a multi-coin selector that accepts up to 8 different coin types at the same time. This type of selector is widely used in vending machines, massage chairs and other self-service systems.

You will use three buttons on the side of the acceptor: Setup, ADD and MINUS. The two-digit display between ADD and MINUS shows which channel you are on and what value it holds.

THREE STEPS

1.1 coin sampling  →  1.2 set the coin value  →  1.3 set the price and run time.

Steps 1.1 and 1.2 are done on the acceptor itself. Step 1.3 is done on the control module. A video is also included below.

Step 1.1 — Coin sampling

Teaching the acceptor which coins to take.

  1. In standby, press Setup once. The display shows L1, steady. L1 is the first of the eight coin channels.
  2. Prepare at least five coins of the same value (ten is better) and insert them one at a time, ten times in total.
  3. After the tenth coin, the display flashes 10 and you will hear a beep. Sampling for that coin is complete.

Step 1.2 — Set the coin value

Telling the unit what each coin is worth.

  1. While 10 is flashing, press Setup again to enter value setting.
  2. Use ADD and MINUS to set the value. The value is what the coin is worth in your own currency — 0.25 for a quarter, 1 for a one-dollar coin, 2 for a two-dollar coin. A lit decimal point at the bottom right of the display means the value is below 1. See the picture below for an example showing $0.25.
  3. Press Setup again to save. L1 (channel 1) is now done — repeat the process for channels L2 to L8 if you have more than one kind of coin.

    PS. If there is a coin you no longer want the machine to accept, set that channel’s value to 0 and it will be rejected.

  4. Keep pressing Setup until the display goes dark. The acceptor restarts and beeps — that beep is your confirmation that the settings are stored.

Factory reset: with the acceptor powered, hold Setup for 5 seconds and release after the beep. All learned coins and values are erased.

Step 1.3 — Set the price and run time

  1. Press SET once. The screen shows the browser setup instructions — that is the other route, described below. To carry on here, press SET again.
  2. Timer Setup appears. Use + and − to change the digit you are on, and SET to move to the next digit.
  3. When the time is set, keep pressing SET until Coin Amount Setup appears. Set the amount the same way.
  4. Press SET once more. The screen repeats back what you set and shows settings saved. You are done.

FAQCommon questions

No power after using it for a while?

Usually the fuse has blown to protect the machine. Check the fuse first. Locate the fuse on the ST-004 · Check the fuse on the ST-005. Two spare fuses are included in the box.

Can I use tokens instead of coins?

Yes. The coin acceptor can be trained to accept tokens in the same way as coins. Tokens are available here.

How do I reset the coin acceptor to factory defaults?

Hold the Setup button on the ST-001 coin acceptor for more than 5 seconds. The acceptor resets to factory settings and you will need to train it again with your coin types.

How do I reset the timer to factory defaults?

There is a factory reset at the bottom of the browser setup page. It clears everything you set on that page, so read the warning there first.

Do customers need to install an app?

Not if the unit is on Wi-Fi — they scan the QR code on the screen and pay in their phone browser. The ScanPay app is only needed where the location has no internet and the unit is running over Bluetooth.

Does the machine still work without internet?

Yes. Coin payment runs fully offline with no network and no account. With no internet at the location, customers can still pay by phone through the ScanPay app over Bluetooth.

The coin acceptor is accepting coins it should not accept.

The sensitivity is set too high. Adjust it down until only the correct coin types are accepted. See the sensitivity adjustment video.

How do I extend my warranty?

You can extend it by one year, for two years in total, by submitting the Sintron Warranty Request Form.

What is the difference between the ST-004 and the ST-004-F?

The ST-004-F is front-opening, while the ST-004 is side-opening. Other specs are the same.
